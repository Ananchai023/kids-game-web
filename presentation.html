🛠️ เตรียมเครื่องมือ

🦴 HTML — โครงสร้าง

เขียนด้วย "แท็ก" ในเครื่องหมาย < > ส่วนใหญ่มาเป็นคู่ เปิด-ปิด

<h1>หัวข้อใหญ่</h1>
<p>ย่อหน้าข้อความ</p>
<button>ปุ่มกดได้</button>

👕 CSS — ความสวยงาม

เลือก element แล้วบอกว่าอยากให้หน้าตาเป็นแบบไหน

h1 {
  color: red;        /* สีตัวอักษร */
  font-size: 40px;   /* ขนาด */
}

🧠 JavaScript — การโต้ตอบ

หลักการ 3 ขั้น: หา element → รอเหตุการณ์ → เปลี่ยนหน้าเว็บ

const btn = document.getElementById("start");

btn.addEventListener("click", function () {
  score = score + 1;   // เพิ่มคะแนน
});

🌐 นำเว็บขึ้นออนไลน์ (ฟรี)

เว็บเราเป็น "เว็บนิ่ง" นำขึ้นโฮสต์ฟรีได้ง่ายมาก เพื่อให้ได้ URL แชร์ได้

  • Vercel / Cloudflare Pages — ฟรี
  • Azure Static Web Apps — คลาวด์ Microsoft (มีแผน Free)
  • AWS S3 / Amplify — คลาวด์ Amazon (ถูกมาก)
